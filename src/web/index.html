需要访问令牌

这个 musicm 监听在局域网地址上，启动时生成了一个访问令牌，并把带令牌的链接打印在终端里。

终端里的那行「打开 http://…/?token=…」直接点开即可；也可以把令牌粘到这里。

用 cookie 登录

扫码登录目前被网易云的风控挡住了（会返回「需要行为验证码」），所以这里只走 cookie 粘贴。 做法：浏览器登录 music.163.com → F12 打开 Network → 随便点一个请求 → 在 Request Headers 里复制 Cookie 那一整行的值。 里面必须包含 MUSIC_U，否则不算登录态。
